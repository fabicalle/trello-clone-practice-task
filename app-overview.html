Product

Features

This app recreates core Trello workflows so users can organize work by boards, columns, and cards with smooth drag-and-drop interactions.

  • Authentication: Registration, login, and secure session refresh with JWT flow.
  • Boards & lists: Create and manage multiple boards with color presets and ordered lists.
  • Cards: Card title and description editing, due dates, and fast movement across lists.
  • Card details: Labels, checklists, checklist items, and completion progress tracking.
  • Due-date awareness: Color-coded due date badges to highlight urgency.

Architecture and Tech

System

The project uses a monorepo with a React SPA frontend, an Express REST API, and a PostgreSQL database accessed through Prisma ORM.

React 18 Vite 5 Tailwind CSS Axios interceptors Node.js + Express 4 Prisma ORM PostgreSQL Zod validation @hello-pangea/dnd
  • Internal communication: Client calls REST endpoints and sends bearer access tokens for protected routes.
  • Token strategy: Access token in React state, refresh token in httpOnly cookie.
  • Response contract: Success uses { data: ... }, errors use { error: "..." }.
  • Data model: Core entities include User, Board, List, Card, Label, Checklist, ChecklistItem.
  • Ordering: Float-based positions reduce full-list reindexing when reordering cards/lists.

Tests

Quality

Testing is layered so the app validates logic, component behavior, and realistic user flows from login to board and card operations.

Server integration tests (Jest + Supertest): auth, boards, lists, cards, and middleware coverage.
Client component tests (Vitest + RTL): AuthContext, board views, card modal, and due-date badges.
E2E tests (Playwright): auth journeys, board flows, list/card interactions, and card detail behavior.
Execution notes: dev and test databases must stay separate before running server or E2E tests.
Risk to monitor: token refresh edge cases and drag-drop rollback scenarios under network failures.
